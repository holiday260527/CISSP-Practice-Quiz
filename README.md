✨ Features
1,168 Practice Questions — Covers all 8 CISSP domains and 4 practice tests.
Bilingual Interface — Switch between English and Chinese.
Fully Offline — No installation, server, account, or internet connection required.
Instant Feedback — Automatic grading with correct answers and explanations.
Wrong Answer Review — Dedicated question pool for reviewing mistakes.
Progress Tracking — Automatically saves answers and statistics locally.
Cross-device Transfer — Export and import progress using JSON files.
Mobile Friendly — Responsive layout for desktop, Android, and iOS.
Dark / Light Themes — Choose your preferred appearance.
Keyboard Shortcuts — Navigate and answer questions efficiently.

🚀 Getting Started
Desktop
Download CISSP刷题系统_官方练习题库.html.
Double-click the HTML file.
Open it using Chrome, Edge, Firefox, or Safari.
Select a chapter or choose the full question bank.
Answer questions and review explanations.

No installation or local server required.

Mobile
Download the HTML file to your phone.
Save it to your local storage.
Open it using Safari, Chrome, or another system browser.

iOS: Files App → Long-press the HTML file → Share → Open in Safari.

Android: Open the downloaded file through your file manager using Chrome or another browser.

Avoid opening the file directly inside WeChat's built-in browser, as some features may be restricted.
💾 Progress Management

Your progress is stored locally in your browser. No data is uploaded to any server.

Feature	Description
Auto Save	Automatically saves answers and progress
Export	Downloads a JSON backup file
Import	Restores and merges progress from another device
Reset	Clears all local answers and statistics
Moving Progress Between Devices
On your current device, click 导出 (Export).
A JSON backup file will be downloaded.
Transfer the JSON file to your new device.
Open the quiz application.
Click 导入 (Import) and select your backup file.

Imported records replace local records for matching questions.

Important: Export your progress before clearing browser data or switching devices.
