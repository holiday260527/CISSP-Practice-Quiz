离线与多端

电脑：双击打开即可，不需要联网

手机：把文件用微信/网盘发给自己，在手机浏览器里打开（iOS 用「文件」App → 共享 → 用浏览器打开）

进度：平时存在本机浏览器里；换设备时点右上角 导出 生成一个小 JSON（如 CISSP刷题进度_20261126_1030.json），发到另一台设备后点 导入，作答记录和错题会合并过去。经过实际测试，导出下载、导入合并、刷新后进度都在
